[SAMPLE TECHNICAL QUESTIONS & ANSWERS]

Q1: What is the core difference between optimistic and pessimistic locking?
A1: Optimistic locking assumes multiple transactions can complete without affecting
    each other, verifying record version stamps at commit time. Pessimistic locking
    places exclusive locks on data records upfront, preventing concurrent access
    until release. Optimistic locking excels in read-heavy, low-contention environments.

Q2: How does React 19 handle concurrent rendering and server actions?
A2: React 19 leverages asynchronous transitions, automatic batching, and native
    action hooks (`useActionState`, `useOptimistic`) to manage pending states
    without manual loading flags, enabling fluid non-blocking UI interactions.

Q3: Explain how vector databases perform Approximate Nearest Neighbor (ANN) search.
A3: Vector databases utilize algorithms like HNSW (Hierarchical Navigable Small World)
    and IVF (Inverted File Index) to construct navigable graph layers or cluster centroids,
    allowing sub-linear search complexity across high-dimensional embedding spaces.
