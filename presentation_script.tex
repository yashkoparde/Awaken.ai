\section{Act III: Deep Dive into Subsystems \& Meticulous Technical Decisions}

\subsection{Subsystem 1: Neural-Link Hybrid Authentication [06:30 -- 08:00]}

\begin{speakercue}{Highlight the resilience engineering and security design.}
Explain how Awaken.ai guarantees 100\% uptime even during cloud service outages.
\end{speakercue}

`Let's start with authentication. In enterprise applications, an authentication failure brings the entire user workflow to a halt. In Awaken.ai, we engineered the \textbf{Neural-Link Hybrid Auth System}.

\textbf{How it Works:}
\begin{enumerate}[leftmargin=*]
    \item \textbf{Primary Route}: High-speed JWT authentication handled by our local PHP/SQLite backend. Session tokens and user profiles are validated in under 3 milliseconds.
    \item \textbf{Secondary Cloud Failover}: If the local endpoint is unreachable, the client automatically synchronizes with \textbf{Supabase Auth} over HTTPS.
    \item \textbf{Local State Persistence}: User state and profile data are encrypted and mirrored to \texttt{localStorage} with user-scoped keys (\texttt{awaken\_profile\_<id>}).
    \item \textbf{Zero-Flash Boot Gate}: The application utilizes an \texttt{isReady} initialization gate at the root level (\texttt{App.tsx}), eliminating ugly layout shift or unauthenticated content flashes during boot.
    \item \textbf{Demo Bypass Mode}: For rapid offline evaluation and interview demonstrations, a zero-network mock candidate bridge is embedded directly into the authentication handshake.
\end{enumerate}

Every API call automatically injects a sanitized \texttt{Authorization: Bearer <token>} header, while our Apache \texttt{.htaccess} rules prevent FastCGI header stripping and block any direct HTTP access to the SQLite database file.''

\vspace{0.5em}

\subsection{Subsystem 2: The Multi-Layer Neural ATS Resume Engine [08:00 -- 10:00]}

\begin{speakercue}{Emphasize the difference between dumb regex and our 5-Layer Hybrid Pipeline.}
This is a core USP of Awaken.ai. Walk through each layer methodically.
\end{speakercue}

`Next, let's look at the cornerstone of our candidate preparation suite: \textbf{The Neural ATS Resume Scanner \& Deep Auditor}.

Most online ATS checkers do one thing: they search for keywords. That is completely insufficient for modern Fortune 500 ATS filters (like Workday, Taleo, and Greenhouse). 

Awaken.ai implements a \textbf{5-Layer Hybrid Auditing Pipeline}:

\begin{techbox}{5-Layer ATS Auditing Pipeline}
\begin{itemize}[leftmargin=*]
    \item \textbf{Layer 1: Section Header Structure Compliance} \\
    Validates the presence of standard parsing headers (\textit{Experience, Education, Skills, Projects, Summary}). If non-standard naming is detected (e.g., 'What I Did' instead of 'Experience'), it flags a structural penalty.
    \item \textbf{Layer 2: Keyword Density \& Semantic Distribution} \\
    Calculates exact and fuzzy frequency ratios against target role profiles (e.g., React, TypeScript, Distributed Systems, Docker, AWS), guarding against both under-indexing and spammy keyword stuffing.
    \item \textbf{Layer 3: Quantifiable Impact Metric Extraction (STAR Framework)} \\
    Uses regex pattern extractors to find quantifiable numbers, percentages, dollar amounts, and team sizes (e.g., \textit{'Reduced latency by 42\%', 'Managed \.5M budget'}). Resumes lacking metrics receive actionable coaching prompts.
    \item \textbf{Layer 4: Action Verb Power Indexing} \\
    Scans bullet points for strong, executive action verbs (\textit{'Architected', 'Engineered', 'Orchestrated'}) versus weak, passive phrases (\textit{'Helped with', 'Responsible for'}).
    \item \textbf{Layer 5: Groq Deep Generative Audit} \\
    Sends the normalized resume to Groq \texttt{llama-3.3-70b-versatile} with a strict JSON schema prompt. The model returns overall score (0--100), ATS compatibility breakdown, critical red flags, missing industry keywords, and line-by-line bullet improvements.
\end{itemize}
\end{techbox}

Total processing time for all 5 layers? \textbf{Less than 650 milliseconds}. The candidate gets an interactive scorecard with real-time copyable recommendations.''
